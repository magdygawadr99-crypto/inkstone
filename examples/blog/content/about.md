I'm Magdy Gawad. I write software, mostly Python, and I like knowing how
the tools I use work on the inside. Lately most of my evenings have gone
into the program that builds this site.

## This site

Everything here is static HTML, built by
[inkstone](/projects/inkstone/) from a folder of Markdown files. There is
no JavaScript you need: the pages read fine without it. What script there is
does small things, like the theme switch, the copy buttons on code blocks and
search.

There are no analytics, no cookies and no comment section. If you want to
tell me I am wrong about something, email is at the bottom of every page
and I do answer it.

## Colophon

Typeface
:   Whatever your system thinks a sans-serif is. No web fonts are loaded.

Colours
:   A warm off-white and a cinnabar red, after the seal paste used on ink
    paintings. There is a dark version; the switch is in the header.

Hosting
:   A small VPS and `rsync`. The whole site is about 600 KB.

Source
:   The posts are plain files in a git repository. The oldest one that
    survived the move is from April 2024; the ones before that were not
    worth keeping.
